# ALSKwela A&E 2027 — Elementary LS3 Mathematics

**Full app name:** Elementary ALS A&E Reviewer LS 3 - Mathematics  
**Home Screen label:** Elem A&E LS3 Math  
**Project status:** independent practice-reviewer draft, not an official 2027 A&E test.

## Deploy to GitHub Pages
1. Create a new repository: `alskwela-ls3-mathematics-reviewer-elementary`.
2. Extract this ZIP; upload its **contents**, not the ZIP itself, directly to the repository root.
3. On GitHub, open Settings > Pages > Deploy from a branch: `main`, `/(root)`.
4. Open the resulting HTTPS site in Android Chrome while online; verify offline files saved.
5. Install using Chrome's Install app / Add to Home screen option where available.
6. Launch the installed reviewer in airplane mode and complete a 30-question test; verify feedback and PDF export.
7. Add the published HTTPS link to ALSKwela using Open Link.

**Important:** The first visit needs an internet connection to cache resources. Offline storage is local to the phone and browser; uninstalling or clearing browser data may erase unfinished trials. No learner answers are sent to a server.

## Quality and accessibility
- Fixed Sets A, B, C each have 30 questions, with 14 Number/Algebra, 11 Geometry, 5 Data/Probability and 9/15/6 difficulty targets.
- Balanced random trial selects 30 different competencies at most once per trial, when feasible. Each question is self-contained and can appear in any order.
- Learners see encouraging correct/incorrect feedback, then Taglish worked computation.
- Direct PDF uses simplified ASCII math symbols for portability (`^2`, `x`, `PHP`); browser **Print > Save as PDF** preserves the original Unicode symbols.
- Questions require academic validation and pilot testing. Trial difficulty is provisional.
